The loop

measure→fix the lowest honest item→re-measure↺

Run it in rounds. Write each round's numbers into a scoreboard row. Stop a round when nothing moves without other people or time. Ticks below are saved in this browser only.

gh repo view OWNER/REPO --json stargazerCount,forkCount,repositoryTopics,description
gh api repos/OWNER/REPO/traffic/views --jq '.count, .uniques'
gh api repos/OWNER/REPO/traffic/popular/referrers --jq '.[] | "\(.count) \(.referrer)"'
curl -s https://api.securityscorecards.dev/projects/github.com/OWNER/REPO | jq '.score'
curl -s https://www.bestpractices.dev/projects/ID.json | jq '.badge_level, .badge_percentage_1'

Referrers matter most: they show which channel actually sent people. Chips show where adhd-status stands today.

Patterns across the eight

  • A picture in the first screen in 6 of 8. The two without one have authority instead.
  • Two or more install paths; npx skills add in 5 of 8.
  • The fastest climbers release every one to two weeks.
  • Badges and topics don't predict rank. superpowers has 0 badges.
  • HN was not the engine. Repo links scored 2 to 3 points every time; the one hit was an essay.

Apply to adhd-status next

  1. Demo GIF at the top of the README: type STATUS, get the table and the button. Script it with vhs.1 hShared by every top repo without built-in authority. This skill's value is visual.
  2. Second install path: make npx skills add maumoya/adhd-status work; check skills.sh.1 h5 of 8 offer it; reaches agents beyond Claude Code.
  3. Submit to the Anthropic plugin directory form.30 minStrongest trust signal open to a solo author.
  4. Awesome lists: ComposioHQ PR now · hesreallyhim issue form from 2026-11-15 · BehiSecc PR · travisvn after some stars.1 hLasting referrers, unlike a post.
  5. Keyless CI (frontmatter, JSON, links) with its badge; eval pass count in release notes.1 hTurns "6 evals" into a visible, checkable claim.
  6. GitHub Pages homepage with GIF, FAQ and Open Graph tags; set as repo homepage.2 hGives search and AI engines a page to cite.
  7. Numbers and a before/after: a messy 40-message thread vs the 4-row board.1 hprompt-master and taste-skill prove value with examples.
  8. Launch posts, one per channel: r/ADHD_Programmers, r/ClaudeAI, X with the GIF, a dev.to essay, then Show HN.1 weekOnly after 1 to 7, so visitors land on a finished page.
  9. Best Practices silver: governance, code of conduct, release process, DCO.2 hScorecard CII 5 → 7, honest for a solo maintainer.
  10. Small release every 1 to 2 weeks with a CHANGELOG.md.ongoingEvery fast climber does it; each release is a reason to post.

Not on the list: anything that fakes stars, reviewers or quotes. Code-Review, Contributors and gold stay where they are until real people join.
